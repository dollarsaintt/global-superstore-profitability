# Source data

Source: [Global Super Store Dataset by apoorvaappz on Kaggle](https://www.kaggle.com/datasets/apoorvaappz/global-super-store-dataset).

The project used `Global_Superstore2.xlsx`, worksheet `Sheet1`: 51,290 order lines and 24 original fields, with order dates from January 2011 through December 2014. Place your separately downloaded copy here using that filename. A Kaggle sign-in may be required. Files from similarly named Superstore datasets are not necessarily interchangeable; the validation script checks size and totals against this project.

Raw data, customer names/IDs, and packaged extracts are not redistributed in this repository. Obtain the data from the credited source and review its current usage terms. No ownership or license over the underlying dataset is claimed. Aggregate analytical outputs are included in `results/`.
